# Creator Intelligence Cards

**Date:** 2026-05-06
**Status:** Approved
**Workstream:** 3 of 4 (Theme → Layout → Creator Intelligence → Brand Matching)

## Problem

The current "Your Identity" card shows basic info (handle, interests, cadence, city, follower/post/engagement stats) but doesn't surface the depth of analysis the algorithm performs. Creators should feel that Wagwan deeply understands their Instagram — their content style, audience quality, and how ready they are for brand deals. This builds trust and makes the matching feel legitimate.

## Design

Replace the single "Your Identity" card with 3 focused cards.

### Card 1: Identity Summary

**Grid:** 1 column
**Data source:** Existing `personaSnapshot` + `identity_graph` + Instagram identity

Displays:

- Instagram avatar + handle
- Archetype label (e.g. "The Cultural Curator")
- Current mode (e.g. "exploring")
- Vibe tags (up to 4 chips)
- One-liner from `personaSnapshot.payload.one_liner`
- Aesthetic + lifestyle labels
- City
- Core contradiction from `personaSnapshot.payload.core_contradiction`
- Followers / posts / engagement rate stats row

This is a condensed, tighter version of the current personality card. Same data, better hierarchy.

### Card 2: Audience & Content Insights

**Grid:** 1 column
**Data source:** Existing Instagram identity fields + new `identity_graph.creatorIntelligence`

**Existing signals (already in identity graph):**

- Engagement tier label (`ig.engagement.engagementTier`)
- Caption intent (`ig.captionIntent`) — how they write
- Content categories top 3 (`identity_graph.contentCategories`)
- Brand vibes top 4 (`identity_graph.brandVibes`)
- Personality scores as mini horizontal bars:
  - Expressive (0-100)
  - Humor (0-100)
  - Introspective (0-100)
- Visual color palette — 4 color swatches from `ig.visual.colorPalette`

**New computed signals (from `creatorIntelligence`):**

- Content consistency score (0-100) — displayed as a labeled bar
- Posting frequency — "X posts/week avg" label
- Audience growth trend — up arrow / stable / down arrow indicator

### Card 3: Brand Readiness

**Grid:** 1 column
**Data source:** New `identity_graph.creatorIntelligence`

- **Brand readiness score** (0-100) — large number with circular progress ring (lime color)
- 4 sub-score bars:
  - Signal completeness — how much profile data the algorithm can read
  - Audience quality — engagement rate relative to follower tier
  - Content consistency — from card 2
  - Category fit — how many brand categories they match
- Each bar shows label + score + filled bar (lime at varying opacity)
- **Improvement hints** — 2-3 short actionable tips below the bars
  - Generated by LLM during refresh
  - Examples: "Post more consistently — your best weeks drive 3x engagement", "Your audience skews 18-25 Mumbai — highlight lifestyle content"

## New Server Module

### `src/lib/server/marketplace/creatorIntelligence.ts`

**When it runs:** During the refresh pipeline, after `identitySynthesis` completes.

**Input:** `identity_graph` object + `profile_data.instagramIdentity` object

**Output:** `CreatorIntelligence` object stored at `identity_graph.creatorIntelligence`

```typescript
interface CreatorIntelligence {
  // Content analysis
  contentConsistency: number; // 0-100
  postingFrequency: number; // posts per week average
  growthTrend: 'up' | 'stable' | 'declining';

  // Brand readiness
  brandReadinessScore: number; // 0-100
  subScores: {
    signalCompleteness: number; // 0-100
    audienceQuality: number; // 0-100
    contentConsistency: number; // 0-100 (same as above)
    categoryFit: number; // 0-100
  };

  // LLM-generated
  improvementHints: string[]; // 2-3 short tips

  computedAt: string; // ISO timestamp
}
```

**Score computation logic:**

- `signalCompleteness`: Count non-empty fields in identity graph (aesthetic, lifestyle, brandVibes, contentCategories, interests, city, engagement) / total possible fields × 100
- `audienceQuality`: Map engagement rate to score. >5% = 100, 3-5% = 80, 1-3% = 60, 0.5-1% = 40, <0.5% = 20. Adjust by follower tier (higher followers with decent engagement scores better).
- `contentConsistency`: Derive from content categories count (more focused = higher), caption intent clarity, and aesthetic label presence. If they have a clear aesthetic + focused categories + consistent caption style = high score.
- `categoryFit`: Count of `contentCategories` that overlap with active brand campaign categories on the platform. More overlap = higher score.
- `brandReadinessScore`: Weighted average of sub-scores (signal 20%, audience 30%, consistency 25%, category 25%)

**Improvement hints:** Call `claude-haiku-4-5-20251001` with:

- The 4 sub-scores
- The creator's top content categories and engagement rate
- Prompt: "Given these creator analytics scores, generate 2-3 short, specific, actionable tips (under 15 words each) to improve their brand matchability. Be direct and practical."

### Pipeline integration

In the refresh pipeline (`src/routes/api/profile/refresh-signals/+server.ts` or equivalent):

```typescript
import { computeCreatorIntelligence } from '$lib/server/marketplace/creatorIntelligence';

// After identitySynthesis completes:
const intelligence = await computeCreatorIntelligence(identityGraph, profileData);
identityGraph.creatorIntelligence = intelligence;
// Save to Supabase as part of the identity_graph update
```
